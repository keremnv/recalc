## Frozen semantic treatment

PY: direct normal `python workload.py`. H0: **unchanged Phase-6 H2** binary/bootstrap/runtime. H1: same Phase-6 observer binary and actual script-interpreter launch, with a Phase-7 experimental bootstrap/root overlay. The only runtime semantic change is `ProxyWorksheet.cell` on a covered child, guarded by a conservative whole-script observation certificate. No C observer code, process launch, capture helper semantics, source freshness, artifact builder/format, decoder, classifier, general fallback or workbook iteration changes. The overlay provides the same native observer's fixed `read_engine_phase6/bootstrap` location with Phase-7 sitecustomize and frozen changed-package helper, and imports frozen runtime/artifact code from the actual repository. Overlay path/import overhead is a possible H1/H0 confound; negative controls and coarse import profile must expose it. No phase-6 file is modified.

Certificate rule, fixed before code: require frozen `A1_ADMIT`; parse the complete source AST; every `.cell` attribute anywhere in the source must be the callee of an immediate `Call`, and every such `Call` must be the value of an immediately read `Attribute` in the exact set `{value, data_type, coordinate, row, column}`. Disqualify any `.cell` alias, bare/assigned/passed/returned/stored cell object, `type`/`repr`/`str`/`isinstance`/`bool`/comparison on the cell object, dynamic observation, or any subscript on a classifier-proven worksheet variable. A source with no `.cell` calls may receive a vacuous certificate but cannot contact this new path. Any parse/parent-shape uncertainty disqualifies. The rule may reject safe code. It does not infer the intended workbook operation or change whole-script admission.

At runtime, use already-persisted merge rectangles. On a covered child in a certified script, return the frozen `ProxyCell` temporary for the certified terminal attribute. Phase-1 `MemoryBook.cell` returns `(None,'n')` there; ProxyCell supplies coordinate/row/column. Record `merged_child_contact` and `merged_child_direct`. In an uncertified script, record `merged_child_contact` and `merged_child_reference`, then call the **unchanged** frozen `ProxyWorksheet.cell` branch; it materializes reference openpyxl as before. Anchor/unmerged coordinates call frozen behavior. No object is returned to user code in a certified expression except the terminal scalar. Unknown named ProxyCell attributes retain frozen fallback. There is no catch-and-retry of script code, no removal of `_real_workbook`, and no refactor of fallback.

Expected fixed-target direct covered contacts per invocation, diagnosed before treatment timing against reference openpyxl: 6, 8, 38 respectively. H0 has one `proxy_operation_escape` reference parse per target invocation. If H1 certification/semantics succeed, H1 target `proxy_operation_escape` parse count is zero and covered-direct count matches 6/8/38. Partial removal is reported as partial; no forced zero. Workbook-iteration negative control must retain its same fallback. Other Phase-6 runtime event routes/counts and all 22 outputs must remain unchanged, apart from new merge diagnostic events and certified target fallback removal.

## Scored command/session protocol

- One unscored warmup per arm/workload on discarded caches after semantic gates. Three scored repetitions per workload, each with independent H0/H1 persistent cache roots initially absent and five real commands per arm. PY runs independently each invocation. The original 22 IDs are shuffled with seed `20261107`; three-arm order cyclically rotates `[PY,H0,H1]` by `(position+rep+invocation)%3`. Workdir files are staged/reset outside the command timer identically for arms. 180-second per-command timeout; first correctness/reuse/fallback violation stops subsequent scoring, leaving partial ledgers invalid for aggregate claims.
- External timer is immediately before command launch through command exit. COLD invocation 1 has no artifact. WARM invocations 2–5 require child-confirmed `REUSED`. SESSION N=1,2,3,5 is the observed sum of full commands from cold start. Timer charges thin observer, real child interpreter/bootstrap, hash/discovery/artifact load/build, proxy/merge path/reference parse, pre/post effect observation and diagnostics. No process-boundary or script change.
- Per workload take median cold over three repetitions; warm median across positions 2–5 within repetition then across three repetitions; session median across repetitions. Ratios are **paired by workload**. Report median, geometric mean, range, faster/slower/tied, 2,000-replicate bootstrap percentile interval (seed `20261107`), and task-cluster sensitivity (22 scripts from 14 tasks). Preserve all raw command and session rows; no unpaired difference of medians or extrapolation.
- Required instrumentation: covered-child contact/direct/reference counts, H0/H1 reference parse count and wall, artifact load, script-process wall, H0/H1 full external wall. New merge events occur only at covered children, not every normal cell. On non-target controls inspect whether overlay/import overhead changed wall materially before attributing gain to merge handling.

## Decisions and stopping

Semantic verdict is independent of speed: `EXACT MERGED-CELL DIRECT SERVING EARNED`, `PARTIAL DIRECT SERVING EARNED`, or `MERGED-CELL DIRECT SERVING NOT EARNED`. Full warm speed uses Phase-6 fixed standard for H1/PY: median <1, >11/22 faster, bootstrap upper <1, with exactness and valid reuse. Separately report H1/H0 causal effect on three targets and full 22. Cold and session endpoints cannot substitute for warm.

Stop for missing identity, changed frozen code/artifact, false certification, new fixture/primary mismatch, stale/corrupt serve, missing `REUSED`, changed non-target fallback, wrong target output, timing identity failure, or architecture/format requirement. Do not broaden the classifier, add a real `MergedCell` shim, change observer code, repair workbook iteration or add another treatment to rescue speed. If implementation defect requires change after pinning, version/hash an amendment **before** rerunning affected gates and scored rows.

H1 experimental code, fixture runner, benchmark and analyzer hashes will be pinned in an implementation identity file **after implementation and before fixture/scored execution**. Deliver the semantic review, this spec, fixture/correctness/timing/session/profile/analysis ledgers and root report. No public product or frozen evidence edits.
