## Repetitions, order and correctness gate

- Before scored timing, run one unscored cold and one second-invocation PY/H0/H1 gate for all 30 exact IDs. Then, only if all gates pass, use one unscored warmup per arm/workload followed by 3 scored repetitions, 5 invocations per repetition. Deterministic workload shuffle seed `20260927`; rotate PY/H0/H1 command order by `(position + rep + invocation) % 3`. Three changed-file repetitions per fixture with the same balanced rotation, each from a fresh staged source.
- Compare exit code, timeout, stdout/stderr bytes and normalized volatile addresses using frozen Phase-3 comparator, and file/package output state. `EXACT` and proven `VOLATILE_ONLY_DIFFERENCE` are admissible; any genuine semantic difference, execution failure, stale artifact, missing child-confirmed reuse or capture failure stops scoring. Report volatile cases separately.
- Classify each representative command `DIRECT_CONTACT`, `REFERENCE_ONLY`, `FALLBACK_AFTER_CONTACT`, or `OTHER` from admission, `direct_served_load`, artifact witness and reference events. H0/H1 class changes require explanation, not post hoc exclusion.
- Reference-only standard fixed before data: report median and geometric paired H1/PY ratios, median signed excess ms, faster/slower counts and a workload-level bootstrap 95% median interval. If median >1, lower interval >1 and median excess >0, call it measurable overhead; a business acceptability threshold is intentionally not invented.
- Report ALL 30 as primary descriptive product-shape view, with direct-contact, reference-only and fallback subsets explicitly diagnostic. Ratios pair same script/workbook/repetition. Use 2000 seeded workload-level bootstrap resamples, seed `20260928`; retain task clustering caveat.
- Stop before scoring if any admitted script can be falsely certified for merged direct serving, or any other blocking correctness/assurance defect is found. Do not modify H0/H1 during validation. A later fix needs a versioned spec amendment, new implementation hashes, fresh correctness gate and fresh scored rows; old empty ledgers are never backfilled.
