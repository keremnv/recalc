# Phase 8 known semantic limits

Status: integration audit, not a claim that arbitrary Python/openpyxl programs are equivalent. `ADMITTED` below means the frozen classifier can return `A1_ADMIT`; it does not imply the behavior is proven safe. The fixed 22/30 identities are only tested samples.

| Expression / observable | Current Phase-7 behavior | Reference openpyxl behavior | Admission and fallback | Severity / integration consequence |
|---|---|---|---|---|
| Covered merged child obtained through `ws.__getattribute__("cell")(r,c)`, then `type`/`repr` | Certificate can say `certified=true` with zero literal `.cell` calls, returns `ProxyCell` directly | Returns `MergedCell` | **Admitted, no reference fallback** in confirmed diagnostic | **BLOCKER**: concrete false-positive certificate and observable difference. See `certificate_review/indirect_cell_result.json`. |
| Covered child via `ws.__getitem__("B1")` | Certificate can say true; `ProxyWorksheet.__getitem__` calls patched `.cell` internally and can yield `ProxyCell` | Returns real `MergedCell` | Admitted, no guaranteed fallback | **BLOCKER**: same bypass; statically demonstrated, dynamic path follows code. |
| `cell.parent is ws` after proxy/reference escape | Real cell's `.parent` is real worksheet; `ws` is a proxy | Both identities refer to the same real worksheet | Admitted in Phase-7 fixture, fallback occurs but identity remains mixed | High; inherited proxy limitation. Cannot claim broad Python object fidelity. |
| `type(ws.cell(...))`, `repr(ws.cell(...))`, `isinstance`, identity or hashing of ordinary direct cell | ProxyCell type/repr/identity differs | Real `Cell` object | Frozen classifier can admit; no fallback for Python built-ins | High; proxy route is exact only where object identity is not observed. |
| `.cell()` return stored in variable/container or passed indirectly | Direct proxy object may escape, with later rich fallback but changed identity | Real cell object | Classifier not a complete escape proof; Phase-7 certificate rejects syntactic direct `.cell` nonterminal uses but indirect calls bypass it | High; require explicit supported observation proof or predeclared reference route. |
| `ws.cell(...).value`, `.data_type`, `.coordinate`, `.row`, `.column` on covered merged child | Direct scalar under Phase-7 certificate | Matching scalar on fixed fixtures/traces | Direct only if certificate true; otherwise real-sheet fallback | Narrow earned behavior on tested syntax; certificate soundness blocker prevents general product use as written. |
| Styles, number formats, merged-cell rich descriptors | Reference materialization through `ProxyCell.__getattr__` or covered-child fallback | Real object state | Admission often blocks lexical rich access; dynamic paths may evade | Not part of narrow contract; fallback remains essential and identity can still differ. |
| Workbook iteration | `ProxyWorkbook.__iter__` materializes full reference workbook | Real iteration | Allowed in some admitted scripts; fallback recorded | Correct on fixed samples; double work and a residual warm loser. |
| Worksheet iteration / rich worksheet methods | Reference sheet materialization | Real worksheet behavior | Proxy fallback; whole-script admission may reject known patterns | Not generally exact for proxy/real identity combinations. |
| Unsupported load options, data-only/read-only modes, unknown workbooks | Normal reference call | Normal reference call | Runtime routes to reference when recognized | Behavior depends on installer being active; observe fallback reason. |
| Source workbook mutation after initial hash/first proxy load | Book is rechecked at `load_workbook` interception, then in-memory representation persists | Reference parse sees bytes at its own load | No lock during later reads | Concurrent mutation consistency not proven; freshness is load-time, not snapshot isolation. |
| Macros, charts, tables, writes and arbitrary openpyxl APIs | Not direct read contract; reference fallback where reached | Full openpyxl | Classifier attempts to reject writes/rich usage | No broad equivalence or write acceleration claim. |
| Changed-file capture after helper or mechanical validation failure | Receipt records helper exit, but native observer returns target status; capture helper's `runtime_failure` does not include `validation_passed=False` alone | No LibreCalc assurance layer | N/A | Assurance blocker for production error policy; requires explicit fail-closed receipt/command rule. |
| Symlinked XLSX or inaccessible workbook during observation | Native `FTW_PHYS` can omit symlink target; some errors terminate observer | Python reference execution may access it; frozen Python capture traverses differently | N/A | Capture scope and error policy must be defined before integration. |

The confirmed indirect merged-cell counterexample is sufficient to stop Phase-8 scored validation. The other limits are independent integration requirements; none should be quietly interpreted as a failure of the 22 fixed benchmark rows that already passed.
