## Final synthesis

### CURRENT ARCHITECTURE IN ONE PARAGRAPH

A general coding agent works through ordinary Python/openpyxl with
view/shell/submit (plus narrowly optional factual helpers) against
workbooks scored under LibreOffice recalc; underneath, and invisible
to the model, a transparent mutation-capture transaction with
generation guards, a shared compiled/indexed substrate, and a
conditional Candidate-A read fast path provide assurance and narrow
deterministic speedups — while every structured authority,
coordination, retrieval-API, mutation-DSL, receipt, and context-
compression branch stands closed or frozen on measured evidence.

### MODEL-FACING SURFACE

Ordinary Python/openpyxl + lightweight view/shell + submit (CORE)
with optional search/periods/inspect (CONDITIONAL, facts-only,
FM-narrow). Closed as model-facing: task/obligation IR, edit plans,
scheduler, execution closure, program groups, query DSL, model-facing
SQL/compiled context, mutation DSL, batch writers, persistent-context
API, deltas, handles, receipts.
