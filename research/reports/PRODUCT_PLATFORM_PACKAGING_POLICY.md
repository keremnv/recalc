# Initial platform and packaging scope

Initial integration support is Linux x86_64 only. The observer is POSIX C and requires fork/exec, wait status, `nftw`, and Linux-compatible file/process semantics. macOS needs a separate observer build and process/FD/signal validation. Windows needs a platform-specific observer. Both remain unsupported until tested; no cross-platform claim is made.

The Hatch wheel build hook compiles `src/librecalc_agent/native/observer.c` and the tiny installed command dispatcher `launcher.c` with `cc`, then tags the wheel `py3-none-linux_x86_64`. The dispatcher resolves the observer and Python interpreter inside its installed environment. It handles the default `run` command without launching an extra Python CLI process; commands or options requiring Python configuration parsing delegate to `librecalc_agent.cli`. The wheel contains both executables and package bootstrap/capture resources. The source distribution includes the C sources and hook, so builders produce a platform wheel; installation from a built wheel does not require a compiler. `doctor` checks the packaged observer. The build does not use research-workspace paths. A release pipeline would need separate wheel builds and a policy for supported glibc levels; the current local wheel tag is deliberately not a manylinux certification.
