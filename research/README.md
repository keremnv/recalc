# Research record (historical and experimental material)

This directory contains historical and experimental material. It is **not** the
current product surface; the product is documented in the repository-root
`README.md`.

- Frozen records are preserved here as historical evidence.
- Older claims in this directory may be superseded by later results. The
  authoritative current claim boundary is the top-level
  `FINAL_CLAIM_REGISTRY.md`.
- The `benchmark-data/` dataset is externally obtained (official SpreadsheetBench-2
  sources) and is not vendored in this repository.
- Frozen evidence must not be rewritten to make history agree with later results.
  Content-preserving moves only; never edit the bytes of a frozen record.
