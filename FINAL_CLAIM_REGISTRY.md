# Final claim registry — research closed

> HISTORICAL — describes `0.2.0rc1` (superseded SQLite-index RC), NOT the
> current `0.2.0rc2` integrated product. Current boundary:
> [docs/EVIDENCE_AND_LIMITATIONS.md](docs/EVIDENCE_AND_LIMITATIONS.md).
> Retained as evidence; do not use for external wording about rc2.

Frozen after the final packaged-RC acceleration validation. This is a claim boundary, not a plan for further mechanism or claim-search experiments.

| Proposed public claim | Final status | Evidence boundary |
| --- | --- | --- |
| Ordinary Python/openpyxl script interface through the packaged CLI | **Supported as a product description** | Frozen wheel and public `run` path verified; examples and ordinary control execution work. |
| Conservative, optional deterministic read acceleration exists | **Supported as a qualified product description** | A1 admission and accelerated load contact occurred. It is not a wall-clock benefit claim. |
| Packaged RC reduces total invocation wall time on eligible read workloads | **Unsupported** | All 22 eligible scripts were slower with fresh index/setup charged; median T/C 2.017. |
| Exact read semantics for all admitted RC workloads | **Unsupported** | Four genuine semantic failures, including workbook iteration and array-formula handling. |
| Fail-closed fallback for all optional-runtime failures | **Unsupported as a broad claim** | Unavailable-cache and predeclared unsupported-source checks passed; admitted workbook iteration did not preserve valid reference execution. |
| Provider input-token or cost savings | **Unsupported** | Frozen token discovery and fresh affordance discriminator did not identify a reproducible, capability-preserving product mechanism. |
| Capability equivalence | **Unsupported** | No formal equivalence test; final read replay found treatment-specific semantic failures. |
| Historical per-read/trace acceleration within narrow fast-path tests | **Internal technical evidence only** | Exact-trace and timing artifacts predate the packaged lifecycle; do not translate them into an RC or public percentage claim. |

The strongest fair statement is: **`librecalc-agent 0.2.0rc1` provides an ordinary Python/openpyxl invocation with an optional read fast path, but the tested packaged fresh-invocation path did not deliver workload-level acceleration and exposed admitted-read semantic failures.** See [RC_ACCELERATION_CLAIM_VALIDATION_REPORT.md](RC_ACCELERATION_CLAIM_VALIDATION_REPORT.md).

Research stop: no new token, formula-error, compiled-context, architecture, or claim-search experiment. A future code fix is product engineering and creates a new package identity; it does not revise the frozen RC result. Public narrative and demo materials must use this registry.
