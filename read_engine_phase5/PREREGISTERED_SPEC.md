## Timing protocol and decision rules

- Each command stages script/workbook bytes before the external timer, then times immediately before `subprocess.run` through exit. Three arms, deterministic balanced cyclic order. One unscored warmup per arm/workload on discarded cache. Three scored repetitions/workload; each repetition starts H0/H1 artifact-absent and executes five actual invocations per arm, one cold then four warm; task state restaged each invocation. Workload order is original primary IDs shuffled with seed `20261105`; arm order cyclically rotates `[PY,H0,H1]` by `(shuffled_position + repetition + invocation) % 3`. Timeout 180 seconds/command; any gate or scored failure stops subsequent rows. No result-driven repeats. Use Phase-4 normalization and stage/compare routines without modifying them.
- COLD = external launch→exit on invocation 1; WARM = same boundary on invocations 2–5, valid only with semantic `REUSED`; SESSION N=1,2,3,5 = observed sums of N complete commands from cold start, no extrapolation. H1/H0 is causal process-shape contrast. H1/PY is resulting product-shaped ratio. Phase-4 archived medians are not same-run controls.
- Per workload, median cold over three repetitions, warm median within repetition over invocations 2–5 then median across repetitions, session median across repetitions. Report paired ratio median/geometric mean/range/faster-slower-tied and 2,000-resample percentile bootstrap median interval, seed `20261105`; task-cluster caveat (22 scripts/14 tasks). Keep all raw rows. Use Phase-4 same-run aggregate speed rule: exact fixed rows, valid warm reuse, median H1/PY <1, >11/22 faster, bootstrap median upper bound <1. H1 records module-entry/import-to-run, config/admission, source SHA, artifact discovery/integrity/build, capture pre, runtime install, script, fallback, artifact decode, post-capture, delta/validation, diagnostics, total internal time, external residual.
